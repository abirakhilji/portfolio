# Abira Khilji — Portfolio Website

A fast, responsive, single-page portfolio website built with plain HTML, CSS and JavaScript — no frameworks, no build step, no dependencies.

🔗 **Live site:** https://fantastic-phoenix-ea401f.netlify.app/

---

## About

My personal portfolio — showcasing my background, skills, projects and experience as a BCA student working across core computer science and applied AI. Full details are on the live site itself.

## Features

- 🎨 Dark technical theme with a blueprint-grid background and glow accents
- 💻 Animated terminal panel that types out a short profile summary
- 🧭 Scroll-spy navigation — highlights the current section as you scroll
- 📱 Fully responsive — clean single-column layout on mobile
- ♿ Accessible — skip link, keyboard focus styles, ARIA attributes
- 🌀 Smooth scroll-reveal animations (respects `prefers-reduced-motion`)
- 🖨️ Print-friendly stylesheet
- 🚫 Custom 404 page

## Built With

- HTML5
- CSS3 (custom properties, no frameworks)
- Vanilla JavaScript
- Fonts: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)

## Running Locally

```bash
git clone https://github.com/abirakhilji/portfolio.git
cd portfolio
```

Open `index.html` directly in your browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This site is deployed on [Netlify](https://www.netlify.com/) directly from this repository. Any changes pushed to the `main` branch are automatically redeployed.
